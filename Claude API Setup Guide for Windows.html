🚀 Claude API Setup Guide

Complete Windows Setup with Subscription & API Key Configuration

Perfect for Data Engineers • 5 Minutes Total

Step 1: Create Anthropic Account & Subscription

1

Go to console.anthropic.com

Open your browser and navigate to console.anthropic.com

If you don't have an account, click "Sign Up" and follow these prompts:

  • Enter your email address
  • Create a strong password
  • Verify your email
2

Set Up Billing (Pay-As-You-Go)

After signup, go to Billing → Plans in the console.

Choose the Pay-As-You-Go plan (free tier is limited; production needs pay-as-you-go).

💡 Note: You get $5 in free credits for the first 3 months. Use them first before your card is charged.
3

Add a Payment Method

Go to Billing → Payment Methods.

Click "Add Payment Method" and enter your credit/debit card details.

⚠️ Important: Your card won't be charged immediately. Only after free credits are used.
4

Set Budget Alert (Optional but Recommended)

In Billing → Usage Limits, set a monthly spending limit to avoid surprise charges.

Recommended: Start with $10/month for experimentation.

Step 2: Generate Your API Key

5

Create API Key

In the Anthropic console, go to API Keys in the left sidebar.

Click "Create Key".

6

Name Your Key (Optional)

Give it a descriptive name like claude-windows-dev or daily-data-nudge.

This helps if you manage multiple keys later.

7

Copy the Key Immediately

A long string starting with sk-ant- appears on your screen.

COPY IT NOW. You will never see it again once you close this page.

sk-ant-v0-abc123xyz... (your actual key will be much longer)
🔒 CRITICAL: This key is like your password. Never share it, never commit it to GitHub, never post it in code reviews.
✓ Done with Anthropic Console
You now have a valid, funded API key. Next: Windows setup.

Step 3: Windows Terminal & Python Setup

8

Check Python Installation

Open PowerShell (search "PowerShell" in Windows Start menu).

Type this command and press Enter:

py --version

Expected output: Python 3.10.x or higher (e.g., 3.11, 3.12)

💡 If not installed: Go to python.org, download Python 3.11+, and during installation, TICK the box "Add python.exe to PATH". Then restart PowerShell.
9

Create Project Folder

In PowerShell, run:

mkdir claude-api-project
cd claude-api-project

You're now inside your project folder.

10

Create Virtual Environment

A virtual environment keeps your project's packages isolated from your system Python.

py -m venv .venv

Wait 30 seconds for it to complete. You'll see a new folder .venv appear.

11

Activate Virtual Environment

Run:

.venv\Scripts\Activate.ps1

Look at your prompt: It should now start with (.venv)

Example: (.venv) PS C:\Users\YourName\claude-api-project>

⚠️ PowerShell Security: If you get an error about "scripts are disabled", run this once: 
Set-ExecutionPolicy -Scope CurrentUser RemoteSigned
Then try activating again.
12

Install Required Packages

Still in PowerShell (with (.venv) active), run:

pip install anthropic python-dotenv

This installs two packages:

Package Purpose
anthropic Official SDK to call Claude API
python-dotenv Reads your .env file (keeps API key safe)

Wait for completion. You'll see: Successfully installed...

Step 4: Store Your API Key Safely

13

Create .env File

In PowerShell, run:

notepad .env

Notepad will open. Paste this (replace with your actual key):

ANTHROPIC_API_KEY=sk-ant-v0-your-actual-key-here
⚠️ IMPORTANT:
  • NO QUOTES around the key
  • NO SPACES before or after
  • Just: ANTHROPIC_API_KEY=sk-ant-...

Save the file: Ctrl+S, then close Notepad.

14

Create .gitignore File

This prevents your .env file from being uploaded to GitHub by accident.

In PowerShell, run:

notepad .gitignore

Paste:

.env
.venv/
__pycache__/
*.pyc

Save and close.

✓ Your API key is now safe.
It's in a .env file on your computer, never in your code, never shared.

Step 5: Test with Your First Request

15

Open VS Code

In PowerShell (still in your claude-api-project folder), run:

code .

VS Code will open with your project folder.

💡 Don't have VS Code? Download it free from code.visualstudio.com. Then install the Python extension from Microsoft.
16

Create main.py

In VS Code, right-click the Explorer panel and select "New File". Name it main.py.

Paste this code:

import os
from anthropic import Anthropic
from dotenv import load_dotenv

# Load API key from .env file
load_dotenv()
api_key = os.getenv("ANTHROPIC_API_KEY")

# Fail fast if key is missing
if not api_key:
    raise RuntimeError("ANTHROPIC_API_KEY not found in .env file")

# Create Claude client
client = Anthropic(api_key=api_key)

# Send one message to Claude
response = client.messages.create(
    model="claude-3-5-sonnet-20241022",
    max_tokens=200,
    messages=[{
        "role": "user",
        "content": "Say hello to Daily Data Nudge viewers in one sentence."
    }]
)

# Print Claude's response
print(response.content[0].text)

Save the file: Ctrl+S

17

Run Your First Request

In VS Code, open the Terminal: Ctrl+` (backtick)

Make sure (.venv) appears in the prompt. If not, run:

.venv\Scripts\Activate.ps1

Then run:

python main.py

Expected output: A friendly greeting from Claude.

🎉 DONE!
Your API key works. You can now call Claude from Python.

Troubleshooting

If something goes wrong, check this:

Error Solution
AuthenticationError: 401 Your API key is wrong or has spaces. Re-check .env file.
ModuleNotFoundError: anthropic Virtual environment not active. Look for (.venv) in prompt.
FileNotFoundError: .env .env file is in wrong folder. Use dir to check.
scripts are disabled Run: Set-ExecutionPolicy -Scope CurrentUser RemoteSigned

Your Final Project Structure

After all steps, your folder should look like this:

claude-api-project/
├── .venv/                  ← Virtual environment (auto-created)
├── .env                    ← Your API key (SECRET - never share!)
├── .gitignore              ← Prevents .env from going to GitHub
├── main.py                 ← Your first Python script
└── (any other .py files)   ← Future code goes here
Remember:
  • .venv = auto-created, never touch it
  • .env = keep secret, add to .gitignore
  • main.py = your code
